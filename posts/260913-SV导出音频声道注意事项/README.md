虽然很多人都说过，调音作品但凡能够混一点音，哪怕加个厕所混响也比引擎直出强；

在B站上听了很多SV的调教后发现，很多新用户不仅仅对混音没有概念，甚至在直出配置上都配置不对，然后又没有习惯用不同设备检查成品，经常出现严重破坏听感的效果。

最常见问题就是有一个声道只有气声，显然这是因为SV导出时，选择了增加气声附加声道或者分离气声附加声道导出；
这种情况下导出的音频文件有两个声道，而几乎所有的解码器、播放器都会将双声道理解成左右两声道；

多数情况下伴奏都是双声道，分离气声附加声道的音频再和伴奏混合时，就会变成一边缺少气声听起来像什么很重的口音，一边只有气声听起来十分刺耳。
但如果使用的是单声道的外设监听，甚至某些播放平台开启声道混合，就完全听不出来这个问题。

当然我觉得更大的问题是，很多人对双声道本身没有概念，只知道双声道比单声道好，但为什么好或者能够做到什么效果完全不清楚；
以至于导出音频时下意识选择双声道输出，或者以为附加声道就会比不附加声道好。

实际上是，如果左右声道的内容完全一样，即编辑器内没有设置声相、合唱站位等属性，那么无论导出单声道还是双声道，实际播放效果是一样的。
因此如果编辑器只导出人声，那么绝大多数情况都只推荐导出单声道，再在DAW里做相位和其他效果。
如果想在SV里带伴奏直出，并且伴奏是双声道的，这个时候才应该选双声道导出。

如果不考虑混音，那么绝大多数用户都是用不上分离气声或者附加气声的。
